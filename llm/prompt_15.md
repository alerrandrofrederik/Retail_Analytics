Use a skill `docs` para escrever o runbook e os guias de uso do projeto, de acordo com o código atual.

O runbook traz cada comando, em ordem, como roda hoje: carga da origem, bundle validate/deploy/run com -p pessoal, reprocessamento e o que fazer quando uma checagem falha. Confira cada comando com --help ou dry run; nunca rode algo que grava dados ou inicia job.

Os guias: um por tarefa repetida (ex.: adicionar uma tabela da fonte, reprocessar um dia, conferir a quarentena).

Pré-requisito: prompts 07 a 09.

Saída: o runbook e os guias, no lugar que você propuser, e o README atualizado com o link.
