Use a skill `toolkit` para gerar o site de documentação do projeto a partir do repositório.

Escreva um script que leia o repo e gere as páginas, para poder reconstruir o site depois de cada release: visão geral (fontes, camadas, últimas execuções), arquitetura desenhada a partir do que roda, linhagem dos dados clicável, grafo de chamadas, modelo de dados, qualidade, execuções e catálogo de dados.

O site fica local: nada é publicado.

Pré-requisito: prompt_15.

Saída: o script gerador e as páginas, no lugar que você propuser.
